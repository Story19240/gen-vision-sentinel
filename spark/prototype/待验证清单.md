### 2.1 坏配置必须被拒绝

构造一份缺少 `contact_roi` 的配置：

```bash
BAD_CONFIG=/tmp/spark_bad_config.json
python - <<'PY'
import json

source = "spark/spark_config.example.json"
target = "/tmp/spark_bad_config.json"
with open(source, "r", encoding="utf-8") as source_file:
    config = json.load(source_file)
config.pop("contact_roi")
with open(target, "w", encoding="utf-8") as target_file:
    json.dump(config, target_file, indent=2, ensure_ascii=False)
PY
```

执行并检查退出码：

```bash
set +e
python spark/prototype/run_offline.py \
  --input spark/images/carbon_brush_sample.png \
  --config "$BAD_CONFIG" \
  --output /tmp/spark_bad_output
echo $?
```

验收标准：

- 退出码为 `2`。
- stderr 明确包含 `missing required ROI key 'contact_roi'`。
- `/tmp/spark_bad_output/metrics.csv` 与 `/tmp/spark_bad_output/summary.json` 均不存在。
- `SparkDetector` 直接处理缺 ROI 配置的首帧时抛出说明配置无效的 `ValueError`。

### 7.4 真实正常录像

素材为 1# 碳刷 A 相机导出的正常运行无火花录像，分辨率 1280×720、25fps、349 帧。实测 0 事件、无误报。

三路门的实测剖面：

- 相对饱和度基线 mean 0.195、σ 0.026，现阈值 0.01，饱和门 349/349 帧全程开启。
- 相对闪烁基线 mean 2.08、σ 1.22，现阈值 0.5，闪烁门 348/349 帧开启。
- 最终由颜色门守住：`color_match_ratio` 峰值 0.339，小于 0.5；`color_hit` 为 0 帧。
- `--baseline` 给出的 `mean + 5σ` 建议值：相对饱和度 0.323，相对闪烁 8.19。
- `falling_bright_pixels` 基线 mean 约 357.9、σ 16.1、建议约 438.5。该基线偏高与验证时手画的下落区 ROI 圈入常亮金属件有关。

### 7.5 AI 生成参考短片

素材为豆包 AI 生成的参考短片，仅作灵敏度参考，不是真实样本。视频为 720×1280、24fps、193 帧，实测检出 2 次事件：3.875s 与 4.708s，均为 `heavy`、`blue_white`，与片中电弧时段吻合。实测 candidate 帧为 33，candidate 最长持续 750ms，下落亮像素峰值 6585。

### 7.6 配置假通过问题与修复

第一轮曾用一份顶层缺少 `contact_roi` 等键的手写配置运行 `run_offline.py`，每帧静默返回全零空结果，但进程退出码仍为 0，生成的 metrics/summary 无法与正常通过区分。第二轮已加入三层修复：

- `run_offline.py` 在正式处理前按首帧尺寸校验三类 ROI，失败时向 stderr 报出缺失键或无效 ROI，退出码为 2，并且不写 `metrics.csv`、`summary.json`。
- `SparkDetector` 处理首帧遇到无效 ROI 时抛出说明配置无效的 `ValueError`；空帧仍返回空结果。
- `self_test.py` 新增第 8 条独立检查，使用缺 `contact_roi` 的配置走真实运行器路径，断言非零退出、明确报错且无 metrics/summary。
