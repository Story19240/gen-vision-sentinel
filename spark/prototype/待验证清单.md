# 火花离线算法原型待验证清单

本清单用于项目主本地电脑的 conda 环境。当前代码未在云端工作站执行验证，本文件只定义命令、预期结果与验收标准，不记录任何未实测数据。

## 1. 环境准备

在仓库根目录执行：

```bash
conda env list
conda create -n gen-vision-sentinel python=3.11 -y
conda activate gen-vision-sentinel
python -m pip install -r spark/prototype/requirements.txt
python --version
python -c "import cv2, numpy; print('opencv-python-headless', cv2.__version__); print('numpy', numpy.__version__)"
```

如果 conda 环境已存在，跳过创建命令。验收标准：

- Python、OpenCV 和 NumPy 均可正常导入并打印实际版本。
- 依赖安装来源和实际版本已记录，供后续复现。

## 2. 七场景自验证

执行：

```bash
conda activate gen-vision-sentinel
python spark/prototype/self_test.py
```

验收标准如下。表中的事件数量均为预期判定，不是实测结果。

| 场景 | 预期确认事件 | 预期等级 | 验收标准 |
| --- | --- | --- | --- |
| `normal` | 0 | 无 | 仅有轻微噪声，不得产生确认事件 |
| `normal_global_drift` | 0 | 无 | 全画面亮度缓慢漂移时，相对量必须抵消共同漂移，不得产生确认事件 |
| `blue_white_spark` | 至少 1 | `light` | 接触区蓝白火花持续约 0.6 秒且无下落亮点，必须确认检出，事件等级为轻级 |
| `orange_spark_falling` | 至少 1 | `heavy` | 接触区橙黄火花持续约 0.6 秒并伴下落亮点，必须确认检出，事件等级为重度 |
| `short_flash` | 0 | 无 | 接触区火花仅闪 2 帧，必须被时序确认门挡住 |
| `steady_lamp` | 0 | 无 | 接触区恒定亮斑不得产生持续帧间波动，必须被闪烁确认门挡住 |
| `spark_outside_contact` | 0 | 无 | 火花位于参考区或接触区之外时，不得触发接触区事件 |

总体验收标准：

- 输出恰好包含上述 7 条场景结果，每条均为 `PASS`。
- 最终汇总包含 `PASSED: 7/7 scenarios met expectations`。
- 进程退出码为 `0`。
- 任一场景为 `FAIL` 时不得通过调整断言或删除用例规避，必须修正检测器或合成参数后重跑。

## 3. 样本图片离线运行

执行：

```bash
conda activate gen-vision-sentinel
python spark/prototype/run_offline.py \
  --input spark/images/carbon_brush_sample.png \
  --config spark/spark_config.example.json \
  --output spark/prototype/results/sample_image
```

验收标准：

- 输出目录包含 `metrics.csv`、`summary.json` 和 `annotated.png`。
- `metrics.csv` 包含样本图片对应的逐帧指标。
- `annotated.png` 画出 contact、reference、falling 三类 ROI；若该帧没有确认事件，不得伪造事件标注。
- `summary.json` 的总帧数与输入图片帧数一致。

## 4. 蓝白火花合成序列

执行：

```bash
conda activate gen-vision-sentinel
python spark/prototype/run_offline.py \
  --scenario blue_white_spark \
  --config spark/spark_config.example.json \
  --output spark/prototype/results/blue_white_spark \
  --fps 25 \
  --frames 60 \
  --seed 20261105
```

验收标准：

- 输出目录包含 `metrics.csv`、`summary.json` 和 `annotated.png`。
- 汇总中确认事件数至少为 1。
- 确认事件等级为 `light`，颜色类型为 `blue_white`。
- `annotated.png` 标出三类 ROI 和确认事件。

## 6. 正常基线统计

执行：

```bash
conda activate gen-vision-sentinel
python spark/prototype/run_offline.py \
  --scenario normal \
  --config spark/spark_config.example.json \
  --output spark/prototype/results/baseline \
  --fps 25 \
  --frames 60 \
  --seed 20261105 \
  --baseline
```

验收标准：

- 输出目录包含 `metrics.csv`、`summary.json` 和 `baseline.json`。
- `baseline.json` 分别包含 `rel_saturation`、`rel_flicker`、`falling_bright_pixels` 的 `mean`、`std`、`p99_9`。
- 每项指标均给出 `suggested_threshold_mean_plus_5_sigma`。
- 正常场景确认事件数为 0。
