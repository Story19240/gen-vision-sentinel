# 发电机与冷却水无人值守智能视觉防护系统

> **系统定位**：工业级发电机核心机组无人值守智能视觉“哨兵”系统  
> **核心硬件**：NVIDIA Jetson AGX Xavier (16GB) + 工业网络摄像机 (1080P H.265) + 中盛科技 8 路以太网继电器  
> **运行性能**：TensorRT 原生 FP16 极速推理 **11.9 ms / 83.6 FPS**，自带 8080 端口 Web 动态监控大屏

---

## 1. 业务目标与两大安全防线

传统发电机组依赖人工定时肉眼巡视，存在高巡检盲区与事故迟滞风险。本系统通过高帧率工业视觉与毫秒级边缘计算，建立以下两大核心安全防线：

```
                           ┌─ 1. 【碳刷火花监测模块】 ──> 毫秒级捕捉滑环接触电弧，杜绝烧毁贵重集电环
发电机无人值守双重安全防线 ─┤
                           └─ 2. 【冷却水断流监测模块】 ─> 6路水管独立并发监测，单管堵塞即报警，防止过热拉缸
```

### 1.1 防线一：发电机碳刷火花打火监测 (`spark`)
* **痛点**：转子碳刷磨损超标、跳动或卡涩时，与滑环接触面会产生剧烈高温电弧（甚至环火），几秒内即可灼伤集电环。
* **对策**：划定碳刷接触面切线狭长 ROI，结合 HSV 亮度瞬时脉冲突变与轻量级 YOLO 目标检测，连续 >200ms 锁定火花即触发保护动作。
  > ⚠️ **已废弃（2026-11-04 项目主定案）**：该 YOLO 监督学习路线已正式停用——现场该发电机基本不产生碳刷火花、真实正样本收集不到（流传火花视频系 AI 生成），监督学习无数据来源。火花检测改走物理信号路线，详见 [碳刷火花监测模块设计文档](docs/碳刷火花监测模块设计文档.md)。
  >
  > C++ 移植的机器分工、依赖、复用边界和 ROI 坐标风险已盘点至 [环境矩阵](docs/ENV_MATRIX.md)。

### 1.2 防线二：发电机 6 路冷却水断流监测 (`water`)
* **痛点**：发电机定转子发热量巨大，依靠多达 6 根出水管同时循环降温。只要任意 1 根细管被水垢泥沙堵塞断流，局部热量无法散出即可导致重大拉缸事故。
* **对策**：
  * **6 路管道独立并发**：多通道独立状态机架构，每根水管拥有独立的动能流与时序窗口；
  * **单管堵塞即报**：任意 1 根水管动能跌破安全线持续超过 **2.0 秒**，系统立即精准锁定并输出该管道的独立报警信号；
  * **自适应防抖双重保险**：日常运行微秒级帧差高频算法；机位发生碰撞移位时自动唤醒 YOLO 扫描全图重新对齐管口。
    > ⚠️ **已废弃（2026-11-04 项目主定案）**：机位移唤醒 YOLO 扫描重对齐属于旧方案，已一并废弃（机位偏移改由锚点抗抖跟踪 + Web 端手动重标定兜底），说明见 [碳刷火花监测模块设计文档](docs/碳刷火花监测模块设计文档.md) 第 0 节。

## 4. 现场工业联动标准（双支柱交割）

系统与客户现场控制系统采用明确的“感知哨兵”与“执行中枢”界面划分：

### 4.1 支柱一：8 路以太网继电器无源干接点 (原生 C++ Modbus-RTU over TCP)
通过控制中盛科技 **`ZS-DO-R-10A-8`** 模块的 Y1 ~ Y8 继电器：
* **`Y1`**：碳刷火花打火告警回路（接入电控柜碳刷保护）
* **`Y2`**：冷却水系统总告警回路（带 `master_alarm_active_` 去重保护，多管并发告警时总回路仅动作一次，接入发电机停机联锁）
* **`Y3 ~ Y8`**：分别对应 **1 号 ~ 6 号冷却水管道**，单管断流独立动作（用于现场故障管道精准定位），供水恢复自动释放。

### 4.2 支柱二：运维人员飞书群机器人实时告警 (全栈纯 C++ 原生驱动)
* **板端零 Python 依赖**：采用原生 `libcurl` + 独立异步线程驱动，断水瞬间 0 微秒阻塞视频主循环向飞书推送**交互式红底卡片**；供水恢复推送**绿底正常卡片**；
* **局域网代理自动发现**：自动探测 `/proc/net/arp` 活跃上位机在 `10811` 端口的代理通道（自动适配 `http://192.168.1.150:10811`）；
* **动态大屏跳转联动**：卡片底部的【🔍 查看现场实时大屏】按钮自动随网络拓扑生成当前有效大屏链接（默认 `http://192.168.1.100:8080`），并支持在 Web 端自由切换为自定义外部域名/穿透 URL，零重启热加载；
* **冷启动与告警风暴抑制**：前 8 秒静音预热期，单管道 60 秒报警去抖冷却，杜绝误报。

## 5. 快速启动与日常运维指令

### 5.1 SSH 登录开发板
支持千兆工业以太网与 USB 调试双通道直连：
```bash
# 千兆交换机工业网络 (推荐)
ssh root@192.168.1.100

# USB 调试线通道
ssh root@192.168.55.1
```

### 5.2 进入同屏协同终端 (tmux)
> **规范要求**：板端所有操作（编译、构建、测试与运行）统一在 **`agent_work`** 会话内执行：
```bash
tmux a -t agent_work
```

### 5.3 启动冷却水动能监控与自适应抗抖 Web 标定服务 (纯 C++)
在开发板 `agent_work` 终端中执行一键启动脚本：
```bash
cd /data/workspace/water/src/test
bash run_analyzer.sh
```
启动后在 Windows 浏览器直接打开：
* 👉 **工业交换机推荐访问**：[http://192.168.1.100:8080](http://192.168.1.100:8080)
* 👉 **USB 调试直连通道**：`http://192.168.55.1:8080`
* 👉 **在线鼠标标定与设置**：页面集成管口绘制、键盘 1~6 快捷绑定、业务延时微调、EMA/Diff/Blur 视觉滤波热加载以及飞书跳转地址管理。
* 👉 **断水模拟演练**：点击顶部「🚨 模拟断流演练」，实测 2 号管模拟断流并在 2 秒内触发硬件继电器闭合与飞书红卡推送。
