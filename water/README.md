# 冷却水监测模块 (Water Flow Monitoring Module)

本目录归档所有关于发电机 6 路冷却水管道的实测视频、自适应抗抖微调算法、断水模拟演练、实时 Web 监控服务、在线标定工具及测试脚本。已严格按照工业工程标准分目录归档。

所有板端操作统一在 **`agent_work`** `tmux` 会话中执行：

### 2. Windows 电脑浏览器直接交互 (无需安装任何开发环境)
* 👉 **工业交换机访问**：[http://192.168.1.100:8080](http://192.168.1.100:8080)（推荐）
* 👉 **USB 调试通道**：`http://192.168.55.1:8080`
* 👉 **在线鼠标标定与管口绑定**：
  * 开机默认进入安全标定状态，直接在画面上按住左键拖拽拉框；
  * **按键盘数字 1~6 键** 秒级绑定 1~6 号水管，按 A 键设定抗抖锚点；
  * 确认标定后点击「🚀 确认标定完成，开始正式监控」，实时动能即刻生效并持久化写入 `water_config.json`；
* 👉 **算法决策与飞书高级设置**：
  * 点击右上角「⚙️ 算法与高级设置」进入专属参数面板；
  * 现场即改即生效微调：报警确认延时、复位延时、飞书冷却时间、EMA 平滑指数、帧差阈值、高斯降噪核；
  * **飞书告警跳转地址管理**：支持【自动探测模式】（自动绑定当前活动 IP）与【自定义模式】（自定义域名或外网穿透地址），零重启即时生效；
* 👉 **模拟断水演练**：点击顶部「🚨 模拟断流演练」（模拟 2 号水管断流，2 秒内变红告警，自动触发硬件继电器 Y2+Y4 动作，并毫秒级向飞书推送红底告警卡片；再次点击恢复供水并推送绿底恢复卡片）。

## 核心算法突破与防抖演进分析

### 1. 刚体锚点自适应抗抖微调 (`AnchorTracker`)
针对**手机手持实拍视频的呼吸晃动**或**工业机位在水轮机运行中的物理震颤**：
1. 系统自动锁定管壁刚性金属支架作为初始锚点；
2. 每一帧通过极速局部模板匹配（`cv::matchTemplate`，耗时仅 0.2ms）实时测算镜头晃动偏移矢量 $(\Delta x, \Delta y)$；
3. **安全限幅保护**：置信度设为 $\ge 0.65$，并强制 $\pm 35\text{px}$ 物理安全限幅，杜绝弱纹理脱靶导致检测框被带偏。

### 2. 现场工业建议与“1对1”演进路线
- **固定机位建议**：由于现场工业摄像头螺丝固定牢靠，机位极稳，工业级最稳妥做法是**采用静态高精度标定（0 锚点）**，杜绝光影水花反光干扰；
- **1对1 专属锚点演进**：避免“1对多”由于广角畸变或微小角度旋转引起的远处杠杆臂放大误差，可将各管道出水框专属绑定其头顶 20px 处的铁管管嘴，管管解耦独立微调。
