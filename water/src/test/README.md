# 冷却水监测系统 C++ 测试与标定工具目录 (`water/src/test`)

本目录专门归档所有用于**画面分析、管口坐标标定微调、机位抗抖动追踪、动能截断分析以及性能压测**的纯 C++ 独立测试程序。与正式主干服务隔离，方便独立验证与调试。

---

## 测试工具清单

| 源码文件 | 编译产物 | 工具定位与说明 |
| :--- | :--- | :--- |
| **`water_flow_analyzer.cpp`** | `water_flow_analyzer` | **纯 C++ 动能看板、抗抖微调、Web 推流与飞书联动一体化监控程序**：内置 GStreamer NVDEC 硬件硬解、**刚体锚点自适应抗抖微调算法 (`AnchorTracker`，带 $\pm 35$px 安全限幅)**、纯 C++ 异步飞书客户端与 Web 服务（8080 端口），支持在 Windows 浏览器中直接查看带框大屏（`http://192.168.55.1:8080`）、在网页上直接用鼠标拉框标定（`/calibrate`），以及一键演练模拟断水（`/cutoff`）。断水 2 秒变红报警并**毫秒级向飞书群推送红底告警卡片**，恢复供水自动推送绿底恢复卡片。 |
| **`calibrate_roi.cpp`** | `calibrate_roi` | **纯 C++ 交互式坐标标定工具**：支持本地 MP4 视频或 RTSP 网络流，按空格暂停视频，鼠标在管口处拖拽拉框，按数字键 `1~5` 绑定给对应管道，按 `S` 键一键将最新坐标写回 `water_config.json`。 |
| **`test_gst_app.cpp`** | `test_gst_app` | GStreamer `appsink` 硬件硬解码稳定性测试。 |
| **`test_imencode.cpp`** | `test_imencode` | JPEG 高速图像压缩基准测试。 |

## 编译与运行方式 (在开发板 Xavier 环境)

在工位 USB 调试环境发飞书时，请先在 Windows 电脑双击运行根目录下的：
👉 **`一键启动电脑过桥代理(飞书上网用).bat`**（保持显式小黑窗开启）。

```bash
# 1. 登录开发板并接入常驻同屏会话
ssh root@192.168.55.1
tmux a -t water

# 2. 进入测试目录并编译
cd /data/workspace/water/src/test
make clean && make -j4

# 3. 运行动能分析与 Web 服务 (加 unset DISPLAY 杜绝 X11 弹窗)
unset DISPLAY && ./water_flow_analyzer
```

## Windows 浏览器访问与在线标定

程序启动后，在您的 Windows 电脑浏览器直接打开：
1. **实时动态大屏看板**：👉 **`http://192.168.55.1:8080`**  
   查看 5 根管口框（绿/橙/红）、抗抖锚点、实时手抖偏移读数（安全限幅 $\pm 35$px，杜绝漂移）、动能数值与 FPS。
2. **在线鼠标画框标定界面**：👉 **`http://192.168.55.1:8080/calibrate`**  
   直接在浏览器画面上用鼠标左键拖拽拉框，点击右侧 `1~5` 号按钮立即绑定管口，点击【机位防抖锚点】设定追踪锚点，通过 HTTP POST **无缝热更新写入开发板 `water_config.json` 且内存中立即生效，无需重启程序**！
3. **断水模拟演练开关**：👉 **`http://192.168.55.1:8080/cutoff`**  
   触发/恢复 2 号管人工截断演练，画面 2 秒内变红报警并**向飞书群推送红底告警卡片**，再次点击恢复绿色并推送绿底恢复卡片。
