# 冷却水监测系统 C++ 测试与标定工具目录 (`water/src/test`)

本目录归档所有用于**发电机冷却水视觉分析、管口坐标标定微调、机位抗抖动追踪、动能截断分析、网络中继继电器联动以及飞书告警压测**的纯 C++ 独立测试与交付程序。与旧版流程隔离，支持独立构建、热更新与全链路联调。

---

## 编译与运行方式 (Jetson AGX Xavier)

> [!IMPORTANT]
> **全局执行规范**：板端所有编译、调试与运行操作必须**严格且唯一**在 `agent_work` tmux 会话中进行，严禁直接在普通终端后台或脱离会话运行！

在宿主机通过千兆工业交换机或 USB 调试发飞书时，请确保 Windows 电脑已启动本地 HTTP 代理（端口 `10811`），程序将自动完成代理握手。

```bash
# 1. 登录开发板并附着至统一运维会话 agent_work
ssh root@192.168.1.100      # 交换机网络 (或 USB 应急网络: ssh root@192.168.55.1)
tmux a -t agent_work

# 2. 进入测试与标定工具目录
cd /data/workspace/water/src/test

# 3. 编译动能分析与全链路服务
make clean && make -j4

# 4. 启动一体化服务 (加 unset DISPLAY 屏蔽 X11 依赖)
unset DISPLAY && ./water_flow_analyzer
```

## Web 控制台访问与在线标定系统 (`http://192.168.1.100:8080`)

服务启动后，在操作员电脑浏览器（推荐 Chrome / Edge）直接访问：
👉 **`http://192.168.1.100:8080`** （USB 应急网段：`http://192.168.55.1:8080`）

### 控制台三大核心功能区

1. **实时动态看板与 Canvas 高性能流视窗**：
   - 查看 5 根管口框（动态标注绿/橙/红状态）、刚体防抖锚点、实时位移补偿数值及各管口动能曲线与实时推流 FPS。
   - 底层采用 HTML5 Canvas 帧绘制与 Blob 及时回收机制，支持全天候长时间挂机监控，杜绝浏览器内存泄漏崩溃。
2. **可视化管口拉框在线标定系统**：
   - 直接在视频画面上用鼠标左键拖拽拉框，点击右侧 `1~5` 号管道按钮完成绑定，点击【机位防抖锚点】设定追踪基准点。
   - 点击【保存配置】通过 HTTP POST 热更新持久化至板端 `water_config.json`，**内存立即生效，无需重启进程**。
3. **断水演练与硬件通道手动测试**：
   - **断水演练开关**：一键触发/恢复 2 号管人工截断演练，状态机判定超时后自动触发硬件继电器吸合与飞书红底卡片报警，恢复供水自动解除。
   - **继电器手动测试**：支持在界面一键点动触发硬件通道，验证 Modbus TCP 链路联通性。
4. **飞书网络配置与热加载联动**：
   - **自动探测 (推荐)**：自动抓取当前服务监听的有效对外网卡 IP（如 `192.168.1.100:8080`），飞书报警卡片一键直达当前大屏。
   - **自定义跳转地址**：支持指定穿透域名或特定网段 IP，具备前端防轮询覆盖锁定机制，支持按回车键即时保存，板端秒级热生效。
